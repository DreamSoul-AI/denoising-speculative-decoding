## 可复现启动方式

从此工作树启动。下面的环境变量只对当前 PowerShell 及其子进程生效；保留既有解释器，不安装依赖，不写全局 Git 配置。每次 `--output-root` 须使用新的源码树外目录。

```powershell
$env:HF_HUB_OFFLINE = '1'
$env:HF_DATASETS_OFFLINE = '1'
$env:CUDA_VISIBLE_DEVICES = ''
$env:OMP_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
$env:PYTHONUTF8 = '1'
$env:GIT_CONFIG_COUNT = '1'
$env:GIT_CONFIG_KEY_0 = 'safe.directory'
$env:GIT_CONFIG_VALUE_0 = (Get-Location).Path.Replace('\', '/')
& D:/anaconda3/python.exe -c 'import torch, runpy; runpy.run_path("tests/run.py", run_name="__main__")' --plan cpu-pr --output-root '<外部新的验证目录>'
```

先导入 torch 是复用本机已验证的原生运行库加载顺序，随后仍执行仓库唯一 `tests/run.py`，未另建运行器。runner 预算420秒、无排除，每个参数项 setup/call/teardown 独立落盘，`summary.json`、`selection.json`、`junit.xml` 保留实际终态。

## 覆盖边界

本批覆盖输入 embedding 路线，按每个实际提交 token 单位步更新。共享2×2协方差、固定 Q/R 和冻结稳态增益是研究简化。输出 hidden 的 delayed bonus 账本、稀疏跳步、真实模型增益、采样分布与吞吐均未验证。旧汇总仍读取旧 `accepted`，新研究需要显式接入 `retained-acceptance-v1`；代码存在与研究有效分别判断。
