# 8B输入输出状态比较

用户明确要求在8B实现output路线，与input的EMA、Holt、Kalman比较接受量和τ，不比较耗时。协议先登记于[研究计划](<../研究计划 Research Plan 去噪推测解码.md>)；实现时序与空间映射见[开发记录](<../开发记录 Development Record/2026-11-21 输出轨迹与8B比较接入.md>)。本记录区分代码验证、实际运行与研究结论。

## 模型、输入与条件

共享Qwen3-8B，BF16、eager、thinking=false、贪心，512输入／64生成上限，单mask、branches=[14]、BC30。实际模型hidden_size=4096，输入与输出头权重不绑定。权重来自用户指定的共享ModelScope缓存，16成员／5分片全量清单保存在共享artifacts，清单SHA256为`23684ffb2f69e15da998eada798e33bb1d7983982f94a1cf9624e210953845de`；没有再下载或替换模型。

Dolly HF revision `bdd27f4d94b9c1f951818a7da7fd7aeea5dbff1a`从共享data池复用，文件SHA256为`2df9083338b4abd6bceb5635764dab5d833b393b55759dffb0959b6fcbf794ec`。排除先前来源实验及4B E1共440个已用文本，seed=20261129，八类先预留eval32（每类4），再取dev8（每类1），无文本重复。输入原文和实际模板token ID冻结保存。

两路线各比较零阶α=.1、差分α=.1/β=.9999、Holt α=.1/β=.99、Kalman Q=diag(.01,.0001)/R=P0=1，八臂均为同一组固定先前4B开发参数，本轮不再选参。dev同样运行，但不据其或eval改参数；比较的是固定参数迁移，不代表分别最优调参。逐prompt轮换臂顺序。额外Jason校准与proxy观测均关闭。

input观测为正式提交embedding；output观测为真实final hidden，bonus hidden延迟到下一轮root，预测距离按实际位置计算。output读出为固定prompt范数归一、实际输出头softmax（温度1）、输入embedding表期望。它支持untied头，但两路线的读出和信息时点不同，不能将差异全归于表示。没有额外完整模型forward；output每轮额外执行预测hidden的头投影和embedding期望矩阵乘，τ不代表这些计算的速度收益。

## 冻结来源与先导

本机共享产物根由`.local/artifacts`接入，此批为`8b-input-output-20261121/`，实际物理根为`D:/GitHub/shared/artifacts/denoising-speculative-decoding/8b-input-output-20261121`。`source/`与`source_manifest.json`冻结701项源码／测试／配置，`研究计划冻结.md`保存执行前协议；`pilot.json`、`pilot-recovery.json`和`main.json`分别声明各个Run，不覆盖原目录。模型数据清单位于共享池，实际哈希和路径保存在配置。

最初`pilot/`被会话中断，没有完成标记，原有部分raw保留且不计入成功总数；确认旧会话不存在后，`pilot-recovery/`用同一冻结源码重新做完整先导。恢复先导16次生成、256输出token，全部逐提交T0及来源声明检查通过，末尾完整权重和源码哈希核对通过，退出0。

`main/`随后执行固定八臂×dev8／eval32。每条生成逐提交落盘，保存A/C/S/N、输出、T0及output位置账本；模型阶段及结果终态重新核对完整权重和源码。完整结果必须由summary、离线raw重审计和配对完整性共同确认，不能以局部控制台行冒充完成。

## CPU与覆盖边界

Windows，Python3.13.9、torch2.11.0+cu130、Transformers5.12.1、RTX5090D v2。启动前可用内存约15.9GiB；8B直接GPU载入，未先复制整个CPU模型。13项输出参数检查和与旧CLI/Study组合的43项检查通过。最终完整CPU计划为1206项通过，无失败或跳过，约260秒；Ruff通过。CPU回执根为DreamSoul资料库`tmp/output-route-cpu-20261121`，回执HEAD是`4a225cb`、dirty=true，实现以本批冻结清单补足，不把基线提交冒充新输出代码。

本批实现连续真实hidden位置流，不包含任意稀疏跳步、soft probe作为噪声观测的融合、Q/R数据拟合或Jason组合。采样分布保证未验证，不额外重启独立AR/BF16算子机理排查。T0只证明自身验证前向的提交链，输出差异仍须报告。
