# 输入状态首轮比较

本轮尚未建立“一阶输入状态优于零阶”的稳定证据，也不支持动态Kalman协方差递推带来验收增量。差分EMA的点估计略高，Holt接近零阶；同Q/R冻结增益优于动态递推，是值得继续核对的切入点。比较对象是输入embedding的简化状态模型，不是Jason仿射hidden校准；没有否定Kalman理论或输出路线。

## 已验证条件与结果

已有Qwen3-4B，BF16/eager、thinking=false、BC30、贪心，512输入／64生成上限。Dolly HF固定版本，排除此前400个已用文本，八类均衡dev8／eval32，eval先预留。差分3组、Holt9组、Kalman9组仅在dev选参，冻结后统一eval；搜索预算不完全相同。来源与完整数表见[运行记录](<../运行记录 Run Record/2026-11-21 输入状态E1实验.md>)。

## 增益轨迹揭示的下一问题

选定Q=diag(.01,.0001)、R=1、P0=I。离线按方程递推（无新模型调用），动态G首次位置／速度权重约[.66777,.33223]，第8步[.38067,.06622]，第32步[.16691,.00996]，稳态[.15903,.00917]。Holt固定权重为[.1,.001]。数列在Run根 `gain_trace.json`。

共同M/V初值不等于早期修正强度相同：P0=I使动态Kalman开头的速度修正明显更强。同Q/R冻结增益改变这段增益时间轨迹，同时以稳态P开始。差异提示先研究初始化／瞬态，但尚不能证明损失完全由瞬态造成；需下一次预登记干预，不能看过eval后补扫Q/R，再将最佳格当确认。

## 后续决定与限制

暂不扩更高阶，也不把复杂度当贡献。下一步隔离P0、稳态初始化与前若干提交的增益安排，在新dev选择并冻结后，用独立输入确认。若仍无增量，保留较简单的零阶／差分，停止把动态协方差当已证贡献。输出路线仍需真实hidden的位置／可用时点账本，不能用输入负结果代替输出实验。

只有一个模型、一次32条均衡留出、短生成、共享2×2协方差与有限比例网格。Q/R未被识别为真实噪声，P0未按数据校准；独立参数重复和跨数据集未执行。区间只作探索，不报告墙钟速度，不与不同协议的Jason旧结果直接排高低，也不宣称采样分布保证。
