# 8B输入输出路线比较

当前固定读出下，output路线整体落后input；但Kalman在output内部出现了可复验的正向线索，不能把两件事混为同一结论。input侧零阶τ=1.5030优于本轮一阶候选；output侧Kalman τ=1.3011，高于自身零阶1.2331，仍低于所有input候选。

## 证据与适用范围

共享Qwen3-8B、BF16/eager、thinking=false、BC30、贪心、512输入／64生成上限。Dolly八类均衡dev8/eval32，排除过去440个已用文本，seed=20261129。两路线四种状态使用先前4B开发确定的固定参数，本轮没有8B选参，也没有分别优化output。完成320次正式生成、20,280个输出token；全部raw重审计通过，160条output时序账本复核通过。完整A/C/S/N、配置、来源与失败/恢复记录见[运行记录](<../运行记录 Run Record/2026-11-21 8B输入输出状态比较.md>)。

| 状态模型 | input A | input τ | output A | output τ |
| --- | ---: | ---: | ---: | ---: |
| 零阶EMA | 684 | 1.5030 | 387 | 1.2331 |
| 差分EMA | 683 | 1.5019 | 382 | 1.2301 |
| Holt | 677 | 1.4963 | 378 | 1.2263 |
| Kalman | 653 | 1.4710 | 472 | 1.3011 |

各臂eval输出N=2037、decode提交S=2005，32条长度逐条一致，但内容并不全部相同；T0不代表独立AR严格等价。output−input的四个探索性τ差区间均低于0（Kalman为−.16992，区间[−.22176,−.12143]）。这支持当前可部署方案下input更好，不支持全局宣称output表示无效。

output Kalman相对output零阶τ增加+.06802，探索性95%区间[.03893,.09675]，约5.52%；A增加85，C减少85，逐prompt调用改善/持平/变差24/3/5。相反，input Kalman相对input零阶为−.03198 [−.05819,−.00333]。因此，同一状态更新在不同观测与读出中表现不同，不能仅用4B input负结果否定output上的状态估计。

## 为什么还不能归因为“output空间好或坏”

8B的输入和输出权重不绑定。本版output追踪真实final hidden，预测目标soft输入前一位置的hidden，再用固定prompt范数归一、实际头softmax和输入embedding期望读出；input直接外推输入embedding。它们既有观测延迟差异，也有读出差异。这是两套完整可部署方案比较，不是只换一份向量的纯单因素实验。

output只用正式位置的真实hidden，没有吸收被拒draft或未到达的bonus，也没有把soft probe输出作为带噪观测进行融合。当前结果不能证明这个未实现的融合方案无效。Kalman的Q/R与P0同样未按8B输出观测流识别为真实噪声；Holt与Kalman固定增益强度不同，正向差异还不足以证明协方差递推是唯一原因。

## 下一步

优先在新的fit/dev上隔离output读出与初值：固定状态比较合法的概率读出和经校准的读出，固定读出比较Holt、动态Kalman、同Q/R冻结增益及P0控制。涉及h_p预测下一位置embedding时，配对标签必须为E[x_(p+1)]，不要错成同位置。只按新dev接受量选取，在新留出确认，不利用本轮eval反向拟合，也不把MSE下降当验收收益。

暂不加更高阶，不追加大网格或测速。当前input零阶仍是简单强基线；output Kalman保留为有条件的正向研究线索。只有一个模型、一次32条留出和从4B迁移的固定参数，区间为探索性条件区间，不是跨模型/跨数据集泛化证明。
