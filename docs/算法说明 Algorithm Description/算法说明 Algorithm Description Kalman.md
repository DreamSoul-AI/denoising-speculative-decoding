# 算法说明 Algorithm Description Kalman

## 当前 input 算法：Kalman 如何介入

2026年11月27日确认。当前只考虑 input，保留 ESP 的公共 block、树注意力、候选选择、验证与缓存处理。探测槽统一读取当前共享水平向量 M，不按槽或树深度额外读出 M+hV。只有探测向量的状态更新发生变化。

| **结构** | **固定增益** | **Kalman 增益** |
| --- | --- | --- |
| 零阶水平 | EMA，按原 ESP 规则对齐的基线 | 零阶 Kalman |
| 水平与趋势 | Holt | 水平—趋势 Kalman |

EMA 与 ESP 的水平递推在 prompt 均值初值、更新 token、顺序／时点和权重一致时对齐，本轮不重复列为两个独立算法臂。原 ESP 来源版本和数值状态仍记录，历史精度或调度差异不冒充算法收益。差分 EMA 若 V 不进入 M 更新或实际读出，对探测无作用，退出当前四臂；M+hV 的显式外推保留为后续另一项改动。

正式提交的 token 给出 input embedding z，依位置顺序更新一次。正常候选节点始终输入自己的 hard token embedding，附属槽输入 soft M。M 更新不重算旧 logits，不修改旧候选。额外 probe 融合、output、Jason 组合、树预算重分配和 Q/R 在线更新均不纳入当前比较。

### 从教程对齐 P、Q、R

先只看一个 embedding 维度。教程的 x 是假设存在的真实平滑状态，M 是其估计，z 是 verified token 的实际 embedding。P 对应教程中的估计协方差 Σ。零均值、无偏及不相关误差是假设，不由 token 确定性自动保证。[教程 §6.1—6.2](https://arxiv.org/html/1710.04055v5#S6.SS1)

| **量** | **标量零阶定义** | **含义** |
| --- | --- | --- |
| P | $\mathbb E[(M_t-x_t)^2]$ | 估计与真实水平之间的误差，推理时递推，不需要知道真实 x 后直接计算 |
| Q | $\operatorname{Var}(x_t-x_{t-1})$ | 零阶模型每一步新增的水平变化 |
| R | $\operatorname{Var}(z_t-x_t)$ | 实际 embedding 相对潜在平滑水平的波动，不是查表误差 |

误差均值为零时平方期望等于方差。有偏时需另外分析偏差，不能默认 P 覆盖所有系统性错误。

### 零阶推理步骤

初始化 M0、P0，冻结校准得到的 Q、R。每个正式 token 到来时：

$$M_t^-=M_{t-1},\qquad P_t^-=P_{t-1}+Q,$$

$$r_t=z_t-M_t^-,\qquad G_t=\frac{P_t^-}{P_t^-+R},$$

$$M_t=M_t^-+G_t r_t,\qquad P_t=(1-G_t)P_t^-.$$

P 的完整递推是 $P_t=R(P_{t-1}+Q)/(P_{t-1}+Q+R)$，不是只加 Q。预测引入新的不确定性，观测融合再降低不确定性。P0、Q、R 给定时，标准增益不直接随当前残差大小改变。每条新样本独立初始化，不跨无关 prompt 连续累加状态。

### 接到 Holt 的水平—趋势结构

对每个维度，$s_t=[M_t,V_t]^\top$，$F=\left[\begin{smallmatrix}1&1\\0&1\end{smallmatrix}\right]$，$H=[1,0]$。按 $s_t^-=Fs_{t-1}$、$P_t^-=FP_{t-1}F^\top+Q$ 预测，用 $r_t=z_t-Hs_t^-$ 和 $G_t=P_t^-H^\top(HP_t^-H^\top+R)^{-1}$ 校正 $s_t=s_t^-+G_t r_t$。协方差可用 Joseph 形式 $P_t=(I-G_tH)P_t^-(I-G_tH)^\top+G_tRG_t^\top$ 更新。

当前候选忽略跨 embedding 维度相关性。每维 P、Q 为 2×2，R 为一个数，G 有水平和趋势两个分量；4096 维对应 4096 份矩阵。每维 Q 可先限制为对角，但递推后的 P 仍保留水平与趋势的协方差。共享 2×2 仅为历史简化／消融；若逐维参数全相同，仅复制存储不会得到不同增益。

### 离线怎样校准

verified embedding 序列提供 z，潜在 x、M/V 的真实状态并未直接观测。因此不能把 embedding 样本方差直接当 R，也不能把相邻 embedding 差分方差直接当 Q。可为固定的状态模型，通过逐步预测的创新似然联合拟合 Q、R 和初始参数。每维预测方差 $S_t=HP_t^-H^\top+R$，高斯模型下负对数似然忽略常数为 $\frac12\sum_t(\log S_t+r_t^2/S_t)$。

calibration 尽量覆盖多个数据集、类别与较大样本，拟合时保持序列边界，不跨 prompt 做差分。记录采用的轨迹、目标解码和来源分布；已有 eval 不反复参与拟合。高维估计可使用共享尺度或收缩，但需说明与逐维独立参数的区别。先限制自由参数并检查可识别性、非负方差和残差相关性。[局部线性趋势的方差参数估计](https://www.statsmodels.org/stable/examples/notebooks/generated/statespace_local_linear_trend.html)

P0 描述初始化误差，不是 prompt token 的样本协方差。它可与初始化规则共同校准，或由当前样本 warm-up 递推得到生成起点协方差。当前只提出估计方法，尚未完成这份 calibration，也没有给出已验证的 Q/R/P0 数值。

### 初始化、calibration 与 warm-up

| **概念** | **作用与数据范围** |
| --- | --- |
| 初始化 | 为每条新样本确定起始 M，Holt 还需 V，Kalman 还需 P。它是起始状态及其产生规则，不等同于某一种数据处理方式 |
| 离线 calibration | 尽量用较大样本、多个数据集或类别估计固定增益、Q/R 和初始状态／协方差的规则或参数。保留各来源身份、分布和数据划分，不能把已看过的 eval 当新拟合集 |
| 当前样本 warm-up | 用该样本推理前已可取得的 prompt、prefill 或明确记录的 preview 信息预热状态。preview 若有额外模型调用或信息须单列，不使用尚未产生的未来 verified 标签 |

calibration 与 warm-up 可以组合。离线学习的可以是根据当前 prompt 产生 M0、V0、P0 的规则，不必给所有样本同一向量。需比较的初始化包括沿用 ESP 的 prompt 均值、当前样本顺序预热，以及离线校准规则。先固定初始化比较四臂，再固定算法比较初始化，不一次混改。

### 推理中更新什么

| **阶段** | **处理** |
| --- | --- |
| 离线 | 校准固定权重或 Q/R，以及 M0、V0、P0 的规则／参数 |
| 当前样本开始 | 按选定规则初始化，并执行已规定的 warm-up |
| 正式推理 | 零阶更新 M、P；一阶更新 M、V、P，同时计算 G，模型权重不变 |
| 留待后续 | 根据近期残差在线估计 Q/R、额外 probe 融合、output 和显式分槽外推 |

误差尺度变化时，在线 Q/R 更新可能有用；若是结构错误或噪声相关，单改 Q/R 未必解决。当前不把这些自适应机制混入标准固定 Q/R 比较。校准似然、向量误差和实际 A/C、τ 分开验收。
