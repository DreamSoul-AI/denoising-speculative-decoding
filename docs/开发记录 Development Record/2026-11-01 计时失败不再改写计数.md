# 2026-11-01 计时失败不再改写计数

解码循环在采样和提交完成后再记墙钟。`perf_counter` 或设备同步抛错时，`prefill_time`、`decode_time`、`ar_time` 和行上的 `spec_time` 缺席，token、接受数、提交数和 `decode_calls` 仍返回。汇总里的 `tokens_per_s` 因此是缺失，而不是 0。

成功路径和把时钟替换成常数 0 的历史读端不变：计时字段仍在，值为经过时间或占位 0。预热把预算改短后会恢复；预热结束时的同步失败不阻止正式解码。
