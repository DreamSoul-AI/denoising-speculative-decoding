# 统一对照与前沿校准接入

为补齐4B／8B同协议比较，状态Study支持显式冻结的arms子集：4B补十一臂，8B仅补缺格，既有合法同协议Run保留。开发及研究条件分别登记在唯一计划，当前研究结论见[统一对照](<../研究记录 Research Record/2026-11-21 4B与8B统一对照.md>)。

新增`FrontierMaskProvider`复用ESP mask更新，在前沿logits上实现Jason 534a79来源公式：`z_post=z_probe+[E(bonus)-placeholder;1]K`。它不是状态Kalman。decode仍由一个循环持有KV与裁剪，只在策略声明需要时取得final hidden；以本次实际使用的旧placeholder及同一前沿bonus构造特征。下一次真实root前向提供相同位置的hidden标签，位置不匹配拒绝，不把draft或未前向bonus当真值。拒绝分支不更新正式EMA。

Study结构层`frontier_matrix.py`负责fit/dev配对、ridge、冻结gain与逐提交审计；flow层仅解析配置。fit与dev来自新的均衡输入，不用eval选参；每模型独立gain，校准SHA入raw来源，结束复核gain、模型及源码。来源decoder只作受控none/full桥接，不复制为第二套宿主decoder，也不改原来源字节。此真实模型桥接尚未执行。

四项针对性检查及完整1210项CPU计划通过。新4B状态对照完成，8B补缺及两模型校准被审批服务额度故障阻断，详见[运行记录](<../运行记录 Run Record/2026-11-21 4B与8B统一对照.md>)。未执行部分不称实现收益已验证；本批未提交／推送／合并／发布。
