更新日期：2026年10月21日。唯一中文计划。项目名“去噪推测解码”为建议，待 Enmao 汇总确认。研究计划规范状态为建议采用，本项目按实际问题裁剪。技术与历史证据只在 [通用调研](<去噪推测解码 通用调研.md>) 维护，不在本文重复数字报告。

# 一、当前状态与目标
研究目标是理解免训练多 token 起草的接受效率：ESP 非官方实现能复现哪些结果，输入/输出 EMA 和速度掩码在什么条件下有用，以及证据能支持何种正确性与效果结论。

8B 三格独立复验已经收口，论文 BC30/60 目标未复现。4B 原五方法及方向六格已完成，范数续跑仅首格完成，剩余七格范数和11格独立配对继续暂停。Enmao 于2026年10月20日20:57确认 K=[A,b] 仿射残差校正可作为独立 Study 推进，先 CPU 小规模，再跨数据集冻结 K，比较无校正/仅 bias/完整 K 三臂。这是已选研究路线，不沿10月18日旧交接把全部新方法都列为未批准。本轮只重组文档并提交 Draft PR，等待架构评审，不 make、launch、载模、下载或执行该路线。

# 五、K 仿射残差校正独立 Study
## （一）已确认路线与公式
采用合作者记号 `K=[A,b]`，校正形式为 `z′ = z + A[e(y)−e(m)] + b`。通式的对象与作用位置随具体协议定义。以下选用已登记的 postcommit CPU 小阶段作为起点，不把该 pilot 的定义外推为合作者通式的唯一解释。

同一已提交前缀记为 `P,y`，P 是前 t−1 个 token，y 为刚提交 token。定义 `m=mean(E[P])`、`e(m)=m`，这里 m 是连续均值 embedding，不是预测 token ID。在同一因果位置 t−1，分别用 `P+soft(m)` 得到最终归一化 hidden `z(m)`，用 `P+E[y]` 得到目标 `z(y)`。残差输入 `x=E[y]−m`，拟合目标 `r=z(y)−z(m)`，校正 z(m)。只使用已经提交的 y，不读取 t 之后 token 或下一词标签。

完整 K 在 fit 行做中心化 float64 ridge，λ=.001，`A=solve(XcᵀXc+λI,XcᵀRc)ᵀ`，`b=mean(r)−A·mean(x)`，截距不正则。仅 bias 臂独立拟合 `b0=mean(r_fit)`，输出 `z(m)+b0`，不能取完整 K 的 b 代替。无校正输出 z(m)。三臂共用数据、模型与提取协议，模型权重不更新。

这是仿射残差校正研究，尚无真正 Kalman 滤波的模型和协方差递推，也没有已证 data-independence、跨数据集泛化或命中率提升。Enmao 的路线确认授权规划该对照，不等于已经验证科学假设。
## （二）先 CPU 小规模，再冻结 K 跨数据集
| **阶段** | **最小安排** | **继续与停止条件** |
| --- | --- | --- |
| CPU 定义与合成检查 | 固定维度、postcommit 位置、残差方向、零残差/零 A/零 b、finite 与中心化求解，检查三臂及独立 b0 | 公式、对齐和输入合同未闭合先停止，不启模型或 GPU |
| CPU 小规模方法检验 | 同一个随机 tied tiny 模型真实提取 latent 对，使用预登记文档划分和下述模型/指标；三臂保留全部结果 | 无模型权重训练，样本不因结果替换或调参，有限性/泄漏/漂移失败即停止 |
| 冻结 K | fit 后先封存完整 A/b、独立 b0、fit IDs/hash、拟合协议与模型空间哈希，再提取 holdout/cross | 不能确认冻结身份则不做跨数据集结论，前后 SHA 必须一致 |
| 跨数据集检验 | K 固定，在未参与拟合/选型的数据集逐样本比较无校正、仅 bias、完整 K，明确分布和模型是否变化 | 保留误差、命中、接受/calls/长度和成本的适用指标，失败/负迁移单列，不以跨集调 K 冒充泛化 |

计划起点为已缓存 WikiText2 test Arrow 的前12篇唯一且至少32 token 的顶层文章，前8 fit、后4 holdout；现有 SpecBench 前8个首轮问题作 cross_dataset。不加 special token/chat template，位置长度4/6/8/10/12/14/16/20，共64/32/64对。按文章划分并核全文/精确前缀跨 split 交集为0，登记文章/tokenizer/input SHA。缓存位置现场从关联资料定位，不写死本机盘符；文件不存在时记录不可执行，不下载或换数据。原缓存名 test 不意味着本次 fit 是独立评测，语料不重新分发。

模型计划为 Transformers tiny LLaMA 随机 seed123、vocab151936、hidden32、intermediate64、2层、4 heads/2 KV heads、positions128、tied、CPU/FP32/eager。tokenizer 只读既有 Qwen3-0.6B 缓存且 `local_files_only=True`，不加载其预训练权重。实际参数数、tied 指针、权重/runtime SHA 由未来运行取得，本轮没有新实测。

主指标为32维 hidden MSE，先每文档8位置平均，再 split 文档等权，报告 holdout/cross 的 full−none 与 full−bias 文档配对差。cosine、LM-head 相对 z(y) 的 argmax 一致和 KL 仅作机制诊断，不是下一 token 标签准确率、τ、接受数或命中率。160对完整、split隔离、位置正确、finite、冻结 K 及来源一致才算有效完成，负结果也可以有效完成，不要求改进才签收执行。

上述数值是固定旧计划中的待执行起点，本轮不把它们标成新冻结产物或实测。实施前核当前代码/缓存/预算适用性，变化须写新 version/Run，不根据结果选好样本。旧计划为 [b72634b 的 K 章节](https://github.com/DreamSoul-AI/denoising-speculative-decoding/blob/b72634b8e391a9df9d5a1f9448f01b471b5dfd22/docs/研究计划%20Denoising%20Speculative%20Decoding.md#k-affine-residual-20261020)，本轮实际读取其该节，没有采用旧分支源码或结果作为 dev 实现。

独立 Study 负责该研究特有的 K 拟合、冻结和三臂配置，复用宿主科学解码/审计，不复制 RPipe 或旧 debt 分支实现。旧分支仅可作实际核对后的资料来源，本轮不抄其结果或当当前代码基线。

# 六、ESP 差距题的后续合同
若重新安排 ESP 差距工作，先回答：固定480输入与 BF16 下，哪个可核验的协议差异能够解释 BC30/60 的 τ 缺口。该问题与独立 K 研究分开，ESP 旧长矩阵继续暂停。作者合同缺失时，只能研究本地非官方实现的敏感性，不能宣布作者差距归因。

1. 在本文新章节写明假设、唯一变量、合理替代解释、基线 commit、输入与模型哈希、停止合同和三种聚合的固定地位
2. 先用已取得旧原件在 CPU 闭合计数；若不同可能结果不改变下一决定，就不增加模型实验
3. 确需新执行时，确认最小配对矩阵、资源预算和停止/恢复条件，建立新 version/Run。旧成功与失败原件不覆盖，来源变化必须显式 make/remake
4. 原始 token、审计、实际运行环境、配置与来源保存到独立运行根；公开正文只回写必要结论和可定位摘要，不在 Study 增加报告群

目标 Study 只包含 `study.yaml`、`experiment_config.yaml` 及实际需要的 `structure/`、`flow/` 薄适配。公共科学方法在标准 Python 宿主包。默认六阶段复用固定 RPipe，当前声明/旧工具迁移须后续实施，不复制整套框架或空模板。

# 七、资源、停止与恢复
未来获准 GPU 执行时单队列串行，准入核对实际 CUDA 计算、可用显存和任务实测 host 峰值加2GiB，显示/远程桌面本身不阻塞，不终止其他任务。历史峰值仅估算起点，运行中仍需测量并保留资源失败，不能保证容量。

正确性/来源/完整性门失败停止验收与依赖扩组，AR 失配仅诊断。取消先停止新派发，正在运行请求保留句柄、部分数据及收尾结果，确认结束后才写取消终态。遇到未知执行结果不自动重试，先核对所属进程、原始文件和冻结身份。

已永久停止 BF16 ESP 相对独立 AR 的算子数值机理排查。ESP 既有比较不改 prompt、不测速、不用 FP32 新开主模型实验。K 作为独立已选路线按第五章先 CPU 小规模规划，其模型/精度/数据条件另行明示，不能用旧 ESP 限制否定最新确认，也不能借 K 自动恢复暂停 GPU 队列。历史“GPU 不空闲”等排班文字不能越过当前暂停状态。
