**去噪推测解码 研究计划**
更新日期：2026年10月21日。唯一中文计划。项目名“去噪推测解码”为建议，待 Enmao 汇总确认。研究计划规范状态为建议采用，本项目按实际问题裁剪。技术与历史证据只在 [通用调研](<去噪推测解码 通用调研.md>) 维护，不在本文重复数字报告。

# 一、当前状态与目标
研究目标是理解免训练多 token 起草的接受效率：ESP 非官方实现能复现哪些结果，输入/输出 EMA 和速度掩码在什么条件下有用，以及证据能支持何种正确性与效果结论。

8B 三格独立复验已经收口，论文 BC30/60 目标未复现。4B 原五方法及方向六格已完成，范数续跑仅首格完成。2026年10月18日交接确认后，剩余七格范数和11格独立配对继续暂停，下一阶段等待 Enmao 评阅确认。本轮只重组文档并提交 Draft PR，不 make、launch、载模、下载或测速。

# 二、研究问题、假设与证据缺口
| **问题** | **可反驳判断与主要对照** | **当前证据及缺口** |
| --- | --- | --- |
| R1 Table 1 差距 | 固定输入与 BF16 设定，某个明确合同差异能否解释 τ 缺口 | 独立复验重复旧差距，聚合与尾部计数未消除；作者模板、权重及完整运行合同仍未知 |
| R2 输出空间方法 | 同一已冻结配方下输出零/一阶能否同时改善接受与调用 | 原五方法不支持优于输入一阶，输出速度项缺稳定联合收益；内部 β、状态精度与路径不同 |
| R3 特定方向唯一性 | e2−e1 若是唯一原因，同范数随机方向应无收益 | 三个随机方向均高于 zero，反驳唯一性；不能推出任意方向等效 |
| R4 范数机制 | 方向×倍率对照能否形成重复、可解释的响应 | 仅0.5×首格及旧0/1端点，七格未完成；不能拟合完整曲线 |
| R5 真实系统收益 | 在固定质量和输出协议下能否减少端到端耗时/资源 | 未测速，τ/调用计数不能代替；当前不纳入执行 |

新颖性未核实，不将“输出空间”“EMA”或“去噪”名称当作新算法贡献。Kalman、协方差与闭环状态估计尚未实现，也不从一阶外推公式推导为已有 Kalman 方法。

# 三、六方面共同约束
| **方面** | **固定内容与规划要求** |
| --- | --- |
| 文献 | 以 ESP v2 方法与 Table 1/G.2 为最接近对照，投机验证基础工作、训练式头/特征起草和检索路线作机制比较。实际阅读深度见通用调研；停止循环寻找未变化作者入口 |
| 数据 | 原 SpecBench480、不改 prompt/模板/顺序以追目标。13个 category 样本量不同，五类各80、八类各10。原数据字节和输入哈希必须核对 |
| 模型 | 8B 仅限既定 Table 1 复现，主研究为4B。新增实验仅在新范围确认后使用 BF16/T0。模型实际 digest、tokenizer/template、EOS、backend 和精度必须固定 |
| 算法 | 明确唯一变化因素、树预算、mask 槽、剪枝、初始化/更新、状态寿命。原生与第三方实现分开，现有输入/输出方法不得因重构暗改语义 |
| 指标 | pooled τ 为主，另列 prompt/category 聚合、accepted、decode/总 calls、输出长度、逐 prompt 胜平负、argmax 全覆盖和 AR 诊断。纯测量不编达标阈值 |
| 实验设计 | 配对单位为 prompt，T0 seed 不冒充随机独立重复。开发集反复使用的480条不能称全新 holdout。负例、失败、资源中断和缺结果全部保留 |

不同输出长度/轨迹不能直接解释为等长速度收益。采样分布无损、独立 AR 等价、同次验证 argmax 和实际质量分别评价。未经明确合同不把一种门升级为其它保证。

# 五、下一阶段开题的最小合同
下一阶段若获确认，先回答一个问题：固定480输入与 BF16 下，哪个可核验的协议差异能够解释 BC30/60 的 τ 缺口。作者合同缺失时，只能研究本地非官方实现的敏感性，不能宣布作者差距归因。

1. 在本文新章节写明假设、唯一变量、合理替代解释、基线 commit、输入与模型哈希、停止合同和三种聚合的固定地位
2. 先用已取得旧原件在 CPU 闭合计数；若不同可能结果不改变下一决定，就不增加模型实验
3. 确需新执行时，确认最小配对矩阵、资源预算和停止/恢复条件，建立新 version/Run。旧成功与失败原件不覆盖，来源变化必须显式 make/remake
4. 原始 token、审计、实际运行环境、配置与来源保存到独立运行根；公开正文只回写必要结论和可定位摘要，不在 Study 增加报告群

目标 Study 只包含 `study.yaml`、`experiment_config.yaml` 及实际需要的 `structure/`、`flow/` 薄适配。公共科学方法在标准 Python 宿主包。默认六阶段复用固定 RPipe，当前声明/旧工具迁移须后续实施，不复制整套框架或空模板。

# 六、资源、停止与恢复
未来获准 GPU 执行时单队列串行，准入核对实际 CUDA 计算、可用显存和任务实测 host 峰值加2GiB，显示/远程桌面本身不阻塞，不终止其他任务。历史峰值仅估算起点，运行中仍需测量并保留资源失败，不能保证容量。

正确性/来源/完整性门失败停止验收与依赖扩组，AR 失配仅诊断。取消先停止新派发，正在运行请求保留句柄、部分数据及收尾结果，确认结束后才写取消终态。遇到未知执行结果不自动重试，先核对所属进程、原始文件和冻结身份。

已永久停止 BF16 ESP 相对独立 AR 的算子数值机理排查。当前不新增 Kalman/方法、不改 prompt、不测速、不用 FP32 新开主模型实验。历史“GPU 不空闲”等排班文字不能越过当前暂停状态。
